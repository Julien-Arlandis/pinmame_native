# Règles du projet

## Sources PinMAME — INTOUCHABLES

Ne jamais modifier les fichiers dans `pinmame_workspace/`.
C'est une base externe. Toute correction passe exclusivement par :
- `engine/api.cpp`
- `engine/node/runtime.js`
- `interface.js`
- `index.html`

Demander explicitement l'autorisation avant toute exception.
Écris et pense toujours en Français !
